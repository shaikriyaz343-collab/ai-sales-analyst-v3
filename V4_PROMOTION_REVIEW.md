# V4 Promotion Review

This branch is a two-parent reconciliation of the V4 product-development line with the current SaaS foundation.

Preserved product-development work includes Forecast, Decision Cockpit, Ask planner, Evidence, Action Workflow, monitoring refinements, and associated tests/UI. The foundation decision-signal semantics and V4 regression gate are also retained.

Promotion remains gated on actual backend regression, frontend build, browser acceptance, security/data-isolation review, and applicable deployment evidence.
